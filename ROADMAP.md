# Roadmap

Ideas that are intentionally outside the current scope. They are written down here so they don't creep into the core version.

## Later

- "What if" DCA calculator with shareable URL state and dynamic Open Graph images
- Exchange presets for CSV import (Coinbase, Kraken, Binance)
- Wallets and accounts, transfers between them
- Average cost method; EUR and GBP display currencies
- Offline support (PWA) and a command palette
- Guides such as "FIFO vs HIFO explained" and pages for individual assets
- Web Worker for parsing and calculations, virtualized tables — only after measurements show a real need
- Print-friendly report, sparklines in the positions table

## Not planned

- Accounts, a backend with user data, sync between devices
- Connecting to exchanges with API keys
- Importing from blockchain addresses, DeFi, NFTs, staking
- Country-specific tax rules or tax form filing
- Stocks and other asset classes, a mobile app, monetization, multiple languages
